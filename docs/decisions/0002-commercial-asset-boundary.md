# 0002 — Commercial asset boundary

**LOCKED — 2026-09-10.** Original commercial workbooks never reach a browser before purchase and authorization. Public source/builds contain only approved public representations. Authentication alone is insufficient.

Private storage plus server entitlement checks enforce this boundary. URL obscurity, browser encryption, disabled download controls and iframe restrictions do not. Signed URLs reduce exposure time after authorization; they are transferable bearer credentials, not DRM.

Reject generating public demos by deploying or importing protected workbooks. Review public demo provenance separately from asset publishing. See [showcase contract](../contracts/showcase.md) and [threat model](../threat-model.md) for release controls.
